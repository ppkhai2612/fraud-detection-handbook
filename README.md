# Reproducible Machine Learning for Credit Card Fraud Detection - Practical handbook

## About

- **Author**: Yann-Aël Le Borgne, Wissam Siblini, Bertrand Lebichot, and Gianluca Bontempi
- **Published**: in 2022
- **Purpose**: This book aims at making a first step in the direction of reproducibility in the benchmarking of payment card fraud detection techniques. Due to the vast amount of published research in the domain, it was not possible to exhaustively review and implement all existing techniques. Rather, this book chose to focus on some of the techniques as the most essential
- **Structure**: 8 chapters
